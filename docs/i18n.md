# Translations (i18n)

Built on [next-intl](https://next-intl.dev) v4.

## Locales and URLs

`src/i18n/routing.ts` lists the locales: `en, es, pt-BR, fr, de, vi, zh-CN, tr, ja, ko`.
English keeps the unprefixed URLs (`/compare`); every other language is prefixed (`/es/compare`).
`src/middleware.ts` runs the next-intl middleware (browser-language detection for first visits,
`NEXT_LOCALE` cookie) after the existing geo-country header logic. All pages live in `src/app/[locale]/`.
Route handlers (`api`, `go`, sitemaps, RSS, llms.txt, robots) stay outside `[locale]`.

## Messages

One JSON file per namespace: `messages/<locale>/<namespace>.json`. Namespaces are listed in
`src/i18n/namespaces.ts`. English (`messages/en`) is the source of truth; a key missing in another
locale falls back to English. Only namespaces in `clientNamespaces` are sent to the browser, so a
`"use client"` component may only read those.

## Writing translatable code

- **Server components / pages**: `const t = await getTranslations("ns")` from `next-intl/server`.
  Every `page.tsx` reads `params.locale` and calls `setRequestLocale(locale)` first (keeps static rendering).
- **Client components**: `const t = useTranslations("ns")` from `next-intl`; `useLocale()` for the locale.
- **Links**: import `Link`, `redirect`, `usePathname`, `useRouter` from `@/i18n/navigation`, never `next/link` /
  `next/navigation` — they add the locale prefix. Hrefs stay locale-free (`href="/compare"`).
  For raw `<a>`, `<form action>`, JSON-LD and canonicals use `localizedPath(locale, path)` /
  `localizedUrl(locale, path)` from `@/i18n/paths`.
- **Metadata**: `buildMetadata({ ..., path: "/compare", locale })` — `path` stays locale-free; it sets the
  localized canonical, `hreflang` alternates and `og:locale`.
- **Numbers / dates**: format with the active locale (`Intl.*(locale, ...)`, `useFormatter`/`getFormatter`), not `"en-US"`.
- **Country names**: `countryName(code, locale, englishName)` from `@/i18n/countries`.
- Use ICU syntax for variables and plurals: `"{count, plural, one {# card} other {# cards}}"`.

## Translation rules

Never translate: card names, brand/issuer names, "Rituel Cards", token symbols (BTC, USDC…), network names,
numbers, percentages, URLs, slugs, ICU placeholders. Use Brazilian Portuguese for `pt-BR` and Simplified
Chinese for `zh-CN`. Keep the tone short, plain and confident.
